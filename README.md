# PokéMory - The Odin Project
This project is part of [The Odin Project](https://www.theodinproject.com) curriculum.
It is a memory game on th e Pokémon theme.
 
## Preview

You can access the website [here](https://pokemory-odin.netlify.app).

## Launch the project
### Prerequisites: Install Node.js
- On Windows
```powershell
winget install OpenJS.NodeJS.LTS
```
- On Linux (Debian/Ubuntu)
```bash
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs
```
### Clone the repo:
- With URL
```bash
git clone https://github.com/Louis-dub/pokemory_odin.git
```
- With SSH
```bash
git clone git@github.com:Louis-dub/pokemory_odin.git
```
### Install dependencies
```bash
npm ci
```
### Launch the project
```bash
npm run dev
```

## Technologies used
- **Node.js**: Runtime environment for managing dependencies via npm (used to bootstrap the project).
- **Vite.js**: Fast build tool and dev server for React apps (scaffolded with npm create vite@latest).
- **React**: JavaScript library for building the UI (default choice in Vite.js templates).
- **Tailwind CSS**: Utility-first styling framework for modern, customizable designs.
